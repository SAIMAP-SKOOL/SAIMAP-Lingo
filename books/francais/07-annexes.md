## Annexe 1 · Les verbes réguliers

| | parler | finir | vendre |
| --- | --- | --- | --- |
| **Présent** | je parle, tu parles, il parle, nous parlons, vous parlez, ils parlent | je finis, tu finis, il finit, nous finissons, vous finissez, ils finissent | je vends, tu vends, il vend, nous vendons, vous vendez, ils vendent |
| **Imparfait** | je parlais, nous parlions | je finissais, nous finissions | je vendais, nous vendions |
| **Passé composé** | j'ai parlé | j'ai fini | j'ai vendu |
| **Futur** | je parlerai | je finirai | je vendrai |
| **Conditionnel** | je parlerais | je finirais | je vendrais |
| **Subjonctif** | que je parle, que nous parlions | que je finisse, que nous finissions | que je vende, que nous vendions |
| **Impératif** | parle, parlons, parlez | finis, finissons, finissez | vends, vendons, vendez |
| **Participes** | parlant, parlé | finissant, fini | vendant, vendu |
| **Passé simple** | il parla, ils parlèrent | il finit, ils finirent | il vendit, ils vendirent |

Particularités des verbes en *-er* : *manger → nous man**ge**ons* ; *commencer → nous commen**ç**ons* ; *acheter → j'ach**è**te* ; *appeler → j'appe**ll**e* ; *préférer → je préf**è**re* ; *payer → je pa**i**e* ; *envoyer → j'envo**i**e*.

## Annexe 3 · *Être* ou *avoir* ?

**Avec *être*** : tous les verbes pronominaux (*se lever, se souvenir*) et les verbes suivants, quand ils n'ont pas de complément direct :

| | | | |
| --- | --- | --- | --- |
| aller | venir | arriver | partir |
| entrer | sortir | monter | descendre |
| naître | mourir | rester | tomber |
| passer | retourner | devenir | revenir, rentrer |

Avec un complément direct, six d'entre eux prennent *avoir* : *J'**ai** monté les valises. · Elle **a** sorti le chien. · Il **a** descendu l'escalier. · J'**ai** passé un examen. · Il **a** rentré la voiture. · Elle **a** retourné la carte.*

**Avec *avoir*** : tous les autres verbes, y compris *être* (*j'ai été*) et *avoir* (*j'ai eu*).

## Annexe 4 · L'accord du participe passé

| Cas | Règle | Exemple |
| --- | --- | --- |
| avec *être* | accord avec le sujet | Elles sont parti**es**. |
| à la voix passive | accord avec le sujet | La loi a été voté**e**. |
| avec *avoir*, COD après | pas d'accord | J'ai écrit **des lettres**. |
| avec *avoir*, COD avant | accord avec le COD | Les lettres **que** j'ai écrit**es**. Je **les** ai écrit**es**. |
| avec *en* | pas d'accord | Des lettres, j'**en** ai écrit. |
| pronominal, pronom COD | accord | Elle s'est lavé**e**. |
| pronominal, autre COD après | pas d'accord | Elle s'est lavé **les mains**. |
| pronominal, pronom COI | pas d'accord | Ils se sont parlé. |
| *fait* + infinitif | invariable | Elle s'est **fait** couper les cheveux. |

## Annexe 5 · L'ordre des pronoms compléments

**Devant le verbe :**

| 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- |
| me, te, se, nous, vous | le, la, les | lui, leur | y | en |

*Il me le donne. · Je le lui donne. · Je lui en parle. · Il y en a.*

**À l'impératif affirmatif :** verbe – *le, la, les* – *moi, toi, lui, nous, vous, leur* – *y* – *en* : *Donne-le-moi. · Dites-le-leur. · Donne-m'en. · Allez-y.*

## Annexe 11 · Les trois liaisons

| Obligatoire | Interdite | Facultative |
| --- | --- | --- |
| déterminant + nom : *les‿amis, un‿ami* | après *et* : *et // elle* | après *être* : *c'est‿ici* |
| pronom + verbe : *vous‿avez, ils‿ont* | devant *h* aspiré : *les // héros* | après *pas, plus, jamais* |
| adjectif + nom : *un petit‿ami* | après un nom singulier : *le train // arrive* | après un nom pluriel : *des amis‿anglais* |
| après *en, dans, chez, sans, très* : *en‿avion* | après un nom propre : *Paris // est* | après un verbe : *ils vont‿au cinéma* |
| expressions figées : *de temps‿en temps, tout‿à coup* | devant *onze, oui* | après *mais* |

Sons de liaison : *s, x, z* → [z] ; *d, t* → [t] ; *n* → [n] ; *f* → [v] dans *neuf‿heures, neuf‿ans*.
